# AXL-Test: Intramural Football League App Starter

This repository now contains a starter planning + scaffolding package for an intramural football league application.

## Included
- Product specification and phased plan.
- Data model and import/sync strategy docs.
- Technology recommendation docs.
- Starter backend API route templates (Express).
- Starter Prisma schema for PostgreSQL.
- Starter frontend components/screens (React/Next-style TSX).
